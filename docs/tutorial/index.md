# Tutorials

- **[Getting started](./getting-started)** (10 minutes): a kernel, a worker in TypeScript, a read model in Python and a request that reads its own write.
- **[Build a shop](./shop/)** (10 parts): a small but complete application, from the first command to a production setup with mutual TLS, authorization and personal data, then accounts and sign-in with the kit and a business process. Every part shows the code in TypeScript, Python and Rust.

Every line of code in these tutorials runs in kernable's test suite, in every language, against a real kernel.
