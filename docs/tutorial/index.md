# Tutorials

- **[Getting started](./getting-started)** (10 minutes): a kernel, a worker in TypeScript, a read model in Python and a request that reads its own write.
- **[Build a shop](./shop/)** (8 parts): a small but complete application, from the first command to a production setup with mutual TLS, authorization and personal data. Every part shows the code in TypeScript and in Python.

Every line of code in these tutorials runs in kernable's test suite, in both languages, against a real kernel.
